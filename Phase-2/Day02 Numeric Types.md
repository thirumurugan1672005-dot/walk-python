# Variables

* Variables should assign before use in any expressions else Name Error
* Variables no need to declare ahead of time
* Variables may change its type during assign new value
* Variables are created when first assigned values

# Arithemetic Operators

* ``+`` : Addition
* ``-``: Subraction
* ``*`` : Multiplication
* ``/``: Division
* ``//`` : Floor Division
* ``**`` : Exponentation

```py
a = 112 + 23
b = 1223 - 23
c = 12 *24
d = 12 / 2
e = 123 // 2
f = 12 ** 2
```

# Comparison Operators

* ``>`` : greater than
* ``<`` : less than
* ``>=`` : greater than or equal to
* ``<=`` : less than or equal to
* `` == ``: equal to
* `` != `` : not equal to

# Comparison Chaining

A < B < C : A < B and B < C
