# Decimals
Decimals are the one which used from module decimals in order to create accurate and set precision on our own

### How to Create the Decimals from Strings
```py
from decimals import Decimal
dec = Decimal('1.23')
```

### How to get from float

```py
from decimal import Decimal
dec = Decimal(12.98)
```
### How to fix the precision using context object

```py
from decimal import Decimal
decimal.context.precision = 3
```
